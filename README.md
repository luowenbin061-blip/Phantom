# 幻影 Phantom —— 自研 iOS 连点器（含屏幕监控）

一个完全自研的 iOS 注入插件：连点/自动化动作 + 屏幕识别 + 命中报警。
功能思路参考公开的同类工具（分析其功能与交互），**代码 100% 自研**，不依赖、不修改任何第三方插件。

## 为什么做

- 手上在用的同类工具是**闭源二进制**，加不了功能（只剩等长小改），他更新就得重来
- 需要一个**自己完全掌控**的版本：能改、能加、能自用、能分发
- 屏幕哨兵（Sentinel）的 OCR/面板/报警/云端 CI 底座已经跑通，直接复用

## v0.1 触摸合成验证（当前）

**目的**：验证 TrollFools 注入环境下，能否用 IOKit 私有 API 合成"系统级触摸"（点击/滑动/录制的地基）。

**验证方法（自证闭环，不需要外部参照物）**：

1. 注入后 5 / 9 / 13 秒，分别用**三种不同策略**（`IOHIDEventSystemClientCreate`、`CreateWithType(0)`、`CreateWithType(1)`）对**幻影自己的悬浮球中心**各发一次合成点击
2. **哪个策略把悬浮球点开了（面板弹出），哪个策略就有效**——不需要你打开别的 App 对照
3. 点悬浮球看面板里的日志：`[策略X] 已派发点击...` / `panel shown`
4. 面板里有「📋 复制日志」和「▶ 重新验证」

**设计原则**：
- 全部私有符号运行时 `dlsym` 解析——缺任何一个都不崩，只记日志
- 模拟器无真实 IOKit → 自动降级（自测断言覆盖）
- 点击前有绿色横幅提示（告诉你现在是哪个策略在点）

## 构建

推 `main` 即触发 GitHub Actions（`macos-14` 云编译，无需 Mac）：

- `build.yml` → `Phantom-dylib`（iphoneos / arm64）+ ldid 伪签名
- `simtest.yml` → 模拟器 e2e：编译 sim 版 → 装 TestHost → `dlopen` 加载 → 内置自测断言

## 安装（真机）

1. 下载 `Phantom-dylib` artifact 解压得 `Phantom.dylib`
2. 传到 iPhone → **TrollFools** 注入到任意 App
3. 冷启动 App → 左侧出现「幻」悬浮球 → 5 秒后自动开始验证序列

## 已知边界

- 需要 iOS 15+ / arm64 / TrollStore 或 TrollFools 环境
- v0.1 只做触摸合成验证，没有连点功能（阶段 1 开始）
- 不发任何网络请求，全部本地
